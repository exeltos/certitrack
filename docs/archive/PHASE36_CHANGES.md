# Phase 36 — Relationships, Invitations & Partner Access
- Canonical invitation lifecycle for registered organizations and email-only invitees.
- Relationship requests require explicit acceptance; no automatic partner access.
- Accept/decline updates both relationship and invitation lifecycle state.
- Cancellation ends a pending linked relationship without hard deletion.
- In-app notifications are created for invited organization owner/admin members and for requester responses.
- Direct client INSERT/UPDATE/DELETE on canonical invitations is removed; RPC lifecycle only.
- Partner certificate access remains enforced by active relationship + `visibility='partners'` RLS from Phase35.
- Added authenticated Netlify email function for pending relationship invitations.
- Updated organization UI flow and canonical status names (`declined`, `ended`).
- No production Supabase changes are performed in this phase.
