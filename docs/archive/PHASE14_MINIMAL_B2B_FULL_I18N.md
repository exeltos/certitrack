# Phase 14 — Minimal B2B + Extended EL/EN

- Neutral B2B visual direction for the public home page.
- Flatter UI: no perspective preview, no decorative gradients, reduced shadows.
- Clearer form controls with stronger borders, explicit disabled-state contrast, and visible focus state.
- Wider account settings form with a structured 3-column desktop layout and responsive collapse.
- Extended EL/EN coverage across navigation, forms, certificate workflows, compliance, supplier access, bulk import, PDF viewer, authentication, alerts, validation and demo content.
- Translation phrases are sorted longest-first to avoid partial translations caused by shorter tokens.
