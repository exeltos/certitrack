# Account security

## Password requirements

Passwords must be at least 12 characters and include an uppercase letter, a
lowercase letter, a number, and a symbol. Greek and Latin letters are both
accepted.

## Two-factor authentication (2FA)

CertiTrack supports authenticator-app-based two-factor authentication
(TOTP — compatible with Google Authenticator, 1Password, Authy, and similar
apps).

### Turning it on

1. Go to your profile settings.
2. Under **Ταυτοποίηση δύο παραγόντων (2FA)**, choose **Ενεργοποίηση**.
3. Scan the QR code with your authenticator app (or enter the shown key
   manually).
4. Enter the 6-digit code your app generates to confirm.

From then on, signing in will ask for your password first, then a 6-digit
code from your app.

### Turning it off

From the same settings section, choose **Απενεργοποίηση** and confirm. We
recommend only doing this if you're changing to a different authenticator
device — turning it off removes the second layer of protection on your
account.
