# CertiTrack

Certificates and compliance between partner organizations. Organizations
connect as equals; each decides, per certificate, which partners can see it,
and CertiTrack reminds both sides before anything they rely on expires.

Static frontend (no build step) on Netlify + Supabase (Postgres, Auth, Storage,
one Edge Function).

## Getting started

```bash
npm install
npm run dev        # http://127.0.0.1:8888 — open /pages/demo/index.html for the in-browser demo
npm test           # unit tests (vitest)
npm run test:db    # schema + 64 privacy tests on a throwaway local Postgres
```

## Layout

| Path | What's there |
|---|---|
| `index.html`, `pages/` | Page shells (generated by `scripts/build-pages.mjs`) |
| `src/pages/` | One module per page: `organization/`, `admin/`, `auth/`, `public/` |
| `src/api/` | Data API: `supabase.js` (live) and `demo.js` (in-browser demo), same interface |
| `src/ui/`, `src/lib/` | Shell, dialogs, components, icons; safe HTML templating, formatting, i18n |
| `src/i18n/` | Greek and English texts |
| `assets/styles/app.css` | The design system |
| `supabase/migrations/` | Database schema (one baseline + future migrations) |
| `supabase/tests/` | Database privacy tests |
| `supabase/functions/` | `process-notifications` (expiry reminders + email) |
| `netlify/functions/` | `finalize_account_erasure` (GDPR erasure, platform admin only) |
| `docs/` | Architecture, security, deployment, operations, legal drafts, user guide |
